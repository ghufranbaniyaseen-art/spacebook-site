# مكتبة SPACEBOOKs

موقع متجر كتب عربي — كتالوج، سلة، إتمام طلب بالدفع عند الاستلام، ومساعد قراءة ذكي.

## البنية الحالية

- **الاستضافة:** VPS هوستنجر (`srv1441669.hstgr.cloud`)، حاوية nginx خلف Traefik.
- **الباك اند:** n8n مستضاف على نفس السيرفر — ورك فلو واحد اسمه `SPACEBOOKs - Store Backend` بيغطي كل شي: الكتب، الطلبات، البانرات، السلاسل، أدمن (كتب/بانرات/سلاسل)، ومساعد القراءة.
- **البيانات:** شيت Google واحد "الكتب والاسعار" فيه ثلاث أوراق: الكتب، السلاسل، البانرات. وشيت "الطلبات" منفصل فيه ثلاث أوراق: الطلبات، خبرني بس يتوفر، اقتراحات الكتب.
- **المساعد الذكي:** Claude (عبر Anthropic API) — بياخد سياق كتب المكتبة المنشورة بس ويقترح منها، بدون ما يخترع كتب مش موجودة.

## الملفات

- `index.html` — الصفحة الرئيسية (الكتالوج، البانر، الأدوات)
- `cart.html` — السلة
- `checkout.html` — إتمام الطلب
- `style.css` — التنسيق
- `app.js` — المنطق المشترك (السلة، جلب الكتب من `/api/books`، فتح الكتاب/السلسلة، المساعد)
- `local-brain.js` — أجوبة جاهزة بالكود لأسئلة شائعة عن التوصيل/الدفع، عشان ما نصرف على Claude إلا لما الكود ما يعرف الجواب
- `problems.js` — مخزون مشاكل القراء والأسئلة الشائعة (بتتدور كل أسبوع)
- `apps-script/Sheet.gs` — كود Google Apps Script بيرقّم الكتب الجديدة تلقائياً وينسخلها القوائم المنسدلة وتنسيقها
- `apps-script/archive/` — نسخ سابقة من `Sheet.gs` لتوثيق كيف تطور
- `assets/` — اللوجو بكل أحجامه والفافيكون
- `prompts/` — برومبتات جاهزة لجمع بيانات الكتب من Goodreads عبر إكستنشن Claude بالمتصفح

## نقاط الوصول (كلها عبر nginx على نفس الموقع، بدون CORS)

| المسار | الوصف |
|---|---|
| `GET /api/books` | الكتب المنشورة (كاش 60 ثانية) |
| `POST /api/submit` | طلب / أعلمني لما يتوفر / اقترح كتاب |
| `POST /api/ask` | مساعد القراءة الذكي |
| `GET /api/banners` *(لسا مش موصولة بالواجهة)* | البانرات المنشورة |
| `GET /api/series` *(لسا مش موصولة بالواجهة)* | السلاسل المنشورة |

نقاط الأدمن (`/webhook/spacebooks/admin/*` على n8n مباشرة، محمية بترويسة `x-admin-key`) لسا ما إلها واجهة مستخدم — الباك اند جاهز ومختبر بس صفحة الإدارة لسا ما انبنت.

## ملاحظة أمان

المفتاح السري لنقاط الأدمن، ومفتاح Anthropic، **موجودين جوّا كود n8n مش بهالـ repo** — ما بينترفعوا لجيت هب أبداً.
